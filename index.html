Study Hub / NOX Cloud Sync is a personal-use synchronization utility that helps its owner move selected TOEFL learning summaries between a Windows Study Hub installation, a private Google Drive folder, and an authorized NOX device.

How it works

Only the data required for the approved learning workflow is synchronized.

01

Study Hub on Windows

Exports selected Coach summaries and separately approved analytics evidence. The original SQLite learning database remains on the user's computer.

02

Private Google Drive

Stores selected JSON files in folders controlled by the Google account owner. OAuth is used to authorize Google Drive access.

03

NOX and optional AI review

An authorized NOX device can read cloud files. The owner may separately connect Google Drive to ChatGPT for learning-plan review; plan execution requires distinct approval.

Google permissions

Windows synchronization: drive.file permits reading and modifying files created or opened through this application's authorization. NOX read-only connection: drive.readonly permits read-only access across the Google Drive account; configuring a preferred sync folder in the client does not reduce the OAuth scope itself.

Access can be revoked by the account owner in Google Account third-party connections. This website does not request Google login credentials and does not host learning records.

中文说明

Study Hub / NOX Cloud Sync 是一个仅供个人使用的学习数据同步工具。它通过 Google Drive 在 Windows Study Hub、获授权的 NOX 设备及用户主动连接的教学分析工具之间共享经过选择的托福学习摘要和证据数据。完整 SQLite 数据库、NOX 人格记忆和 OAuth 密钥不会通过本网站公开。

Windows 端采用 drive.file 授权，NOX 只读端采用 drive.readonly 授权。后者虽然只用于指定同步目录，但授权范围本身覆盖 Google Drive 中可访问的文件。具体见 隐私政策。
