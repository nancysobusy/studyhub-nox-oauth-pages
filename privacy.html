Privacy policy

Effective October 11, 2026 · Personal-use project

1. About this application

Study Hub / NOX Cloud Sync is an independently operated personal utility for synchronizing selected TOEFL learning records between the owner's Windows Study Hub, their Google Drive account, and an authorized NOX device. It is not a public cloud storage or account-hosting service.

2. Google data accessed and permissions

The Windows client uses the Google Drive drive.file scope to create, read, and manage files made available to this application. The NOX device currently uses drive.readonly, a read-only scope that can authorize reading files across the connected Google Drive account. Setting a synchronization folder in the application is a functional limit in the client, not a restriction on the OAuth grant.

3. What data is used, and why

With the account owner's consent, the utility processes selected Study Hub Coach summaries, current plans, task and review status, limited training history, a 90-day analytics evidence summary, and a Library availability summary. These JSON records are used for continuity, evidence-based planning, and authorized device synchronization. Additional data categories require separate owner authorization.

The standard synchronization workflow does not upload the complete Study Hub SQLite database, raw learning-material bodies, the NOX personality/memory store, or OAuth client secrets to Google Drive. The application website itself does not collect these records.

4. Where data is stored and shared

Selected JSON files are stored in the owner's Google Drive account and limited local caches. The owner controls access to their Drive account. The utility does not sell Google user data or make learning records publicly available. If the owner separately authorizes an integration such as ChatGPT's Google Drive connection for teaching analysis, that integration may read the selected records as authorized by the owner; the integration provider's own privacy terms also apply.

5. Data retention and deletion

Some files are retained as versioned snapshots to support continuity and auditing; there is no fixed automatic deletion period in the current personal-use implementation. The owner can remove uploaded records from Google Drive and delete local caches. Revoking Google authorization prevents future access but may not automatically delete already-created Drive files or local caches.

6. Security and access

OAuth access and refresh tokens are stored in configuration files on the owner's authorized devices, not in this public website or repository. The sync client limits its routine operations to configured folders and verifies uploaded files by readback, but device and Google-account security also depend on the owner's security settings.

7. Choices and revocation

The owner may revoke access in Google Account third-party connections, disable local synchronization, or delete the cloud files. Changes to the authorized data scope require owner approval.

8. Site analytics and cookies

This static website contains no application login, advertising scripts, tracking pixels, or first-party analytics cookies. GitHub Pages, as the hosting provider, may process standard web requests under its own policies.

9. Changes and contact

This policy will be updated when synchronization features or permitted data use change. For site or privacy inquiries, use the project's GitHub Issues. Do not post personal learning records or OAuth credentials in public issues.

隐私政策中文摘要

本工具仅供个人使用，通过 OAuth 将经过用户授权的 Study Hub 学习摘要和教学证据同步到用户自己的 Google Drive，并供获授权的设备或用户主动连接的教学分析工具读取。Windows 使用 drive.file；NOX 使用 drive.readonly，后者在授权层面可能读取整个 Google Drive，而不仅限于指定文件夹。

常规同步不上传完整 SQLite、原始素材正文、NOX 人格记忆或 OAuth 密钥。同步记录可能保留历史版本，目前没有固定的自动清理周期。用户可以在 Google 账号授权管理撤销访问，并在 Google Drive 手动删除已上传文件。公开网站自身不收集学习资料。
