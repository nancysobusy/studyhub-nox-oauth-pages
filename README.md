# Study Hub / NOX Cloud Sync — OAuth information website

This public repository contains **only** the static homepage and privacy policy for a personal Google Drive synchronization utility. It is not the Study Hub or NOX application source repository and does not contain learning data, OAuth credentials, SQLite databases, or application runtime code.

Site (once Pages is enabled): https://nancysobusy.github.io/studyhub-nox-oauth-pages/

Privacy policy: https://nancysobusy.github.io/studyhub-nox-oauth-pages/privacy.html

To publish: Repository → Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Google Search Console verification is a separate owner-approval step. If Google requires ownership verification, use a URL-prefix property and add the supplied verification file/meta tag to this repository, then retry verification. Never publish OAuth tokens or client secrets.
